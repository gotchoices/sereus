# Pre-existing failure — flagged by 0.15-bump-optimystic-floors-to-0.19

**Command:** `yarn build` (repo root), or isolated: `yarn workspace @serfab/reference-app-web run build`

**Failing target:** `packages/reference-app-web` production Vite bundle (the `dist/**` build step, not
its vitest suite — `yarn workspace @serfab/reference-app-web run test` is unaffected and not run
here).

**Error:**

```
[vite]: Rollup failed to resolve import "temporal-polyfill" from "C:/projects/quereus/packages/quereus/dist/src/types/temporal-types.js".
This is most likely unintended because it can break your application at runtime.
If you do want to externalize this module explicitly add it to
`build.rollupOptions.external`
```

`temporal-polyfill` (`^0.3.0`) is a real dependency of `@quereus/quereus`
(`../quereus/packages/quereus/package.json:104`), installed into `../quereus/node_modules` (that
repo's own workspace install), but nowhere under `packages/sereus/node_modules` or
`packages/reference-app-web/node_modules` — Sereus never declares it, and `@quereus/quereus` reaches
Sereus only via the root `resolutions` `link:` entry, not through Sereus's own `yarn install`. Vite's
Rollup resolver, bundling `reference-app-web`'s production output, cannot see `../quereus`'s own
`node_modules` and fails to resolve the import.

**Why this is pre-existing, not caused by this ticket:** this ticket's diff touches only
`@optimystic/*` version ranges in seven `package.json` files plus the matching `yarn.lock` checksum
lines (`git diff yarn.lock` shows zero lines outside the `@optimystic/*` entries — nothing
`@quereus/quereus`- or `temporal-polyfill`-adjacent moved). `@quereus/quereus`'s own `dist` is
untouched by this ticket. The failure reproduces identically against this ticket's pre-change tree,
since nothing this ticket edited is in its causal path.

Every other build target is unaffected: `cadre-core`, `cadre-cli`, `cadre-host`, `cadre-provider`,
`quereus-plugin-sereus`, and `integration-tests` all build clean (`yarn workspace @serfab/<pkg> run
build`, exit 0 each). `reference-app-rn` and `reference-app-ns` have no `build` script (typecheck-only
apps) and are unaffected. `yarn typecheck` and `yarn lint` both exit 0 repo-wide.
