- `yarn test` (vitest) — 17 test files / 112 tests fail
- `yarn typecheck` (`tsc -p tsconfig.typecheck.json --noEmit`) — fails

## Why this is pre-existing (not from this ticket)

This ticket (`filekeystore-atomic-write`) touches only
`packages/cadre-core/src/key-store-file.ts` and
`packages/cadre-core/test/key-store.spec.ts`. Neither uses `digest`/`sign`, and
neither appears anywhere in the failure list. The failures are an arity mismatch
between cadre-core's 4-arg `digest(payload, 'sha256', 'utf8', 'bytes')` call sites
and the `optimystic/quereus-plugin-crypto` `digest()` signature (now 1-3 args, no
encoding param) — fallout from the recently merged
`sereus-cadre-schema-digest-api-migration` work (commits `5d22035` / `c301122`),
where the optimystic crypto API changed but these cadre-core call sites were not
migrated. They fail identically on HEAD before this ticket's edits.

## Work-around

None needed for this ticket. My change validated independently:
`yarn vitest run test/key-store.spec.ts` → 21 passed, 1 skipped (the POSIX-only
permission assertion, skipped on Windows). `npx eslint` on both changed files →
clean. I did not disable or modify any of the failing tests.
