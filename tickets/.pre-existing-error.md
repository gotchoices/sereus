# Pre-existing failure: `yarn dep-check` is red (knip "unused dependency")

Surfaced while verifying `32.3-feat-cadre-host-strand-api` (implement stage).

## Command

From the repo root:

```
yarn dep-check      # → knip && yarn check:dep-ranges
```

Exit code **1**. `check:dep-ranges` never runs, because `knip` fails first.

## Failure

```
Unused dependencies (1)
@serfab/cadre-cli  packages/integration-tests/package.json:39:6
```

`dependencies` is one of the gate-failing rule categories in `knip.ts` (the dead-code
categories — `files`, `exports`, `types`, `duplicates` — are `warn` and do not fail the gate;
the run also prints those, but they are noise here).

## Why it is pre-existing

- `packages/integration-tests` never *imports* `@serfab/cadre-cli`. It resolves the CLI's **bin
  path** at runtime to spawn it as a child process:
  `packages/integration-tests/src/harness/provider-process-orchestrator.ts:105` —
  `req.resolve('@serfab/cadre-cli/bin/cadre.js')`. knip cannot see a string-literal `require.resolve`,
  so it reports the declared dependency as unused.
- `packages/cadre-host` already carries exactly this ignore for exactly this reason
  (`knip.ts:52-54`: "Resolved at runtime via `req.resolve('@serfab/cadre-cli/bin/cadre.js')` to
  spawn the CLI as a child process; never statically imported"). `packages/integration-tests`
  has an `ignoreDependencies` block (`knip.ts:60-64`) but no entry for `@serfab/cadre-cli`.
- Both the dependency declaration and the `req.resolve` call landed in commit `fdaa837`
  (`ticket(implement): provider-seed-accepted-by-real-node`), several tickets before this one.
  `tickets/.pre-existing-known.md` records `yarn dep-check` as **exit 0** on 2026-07-30, i.e.
  before that commit — so the gate went red there, not here.
- This ticket's diff touches `packages/cadre-host/src/**`, one scenario file in
  `packages/integration-tests/src/scenarios/`, and `docs/cadre-host.md`. It declares no
  dependency and removes no import, so it cannot have caused an unused-dependency finding.
  Nothing in the knip output names any file this ticket added or changed.
