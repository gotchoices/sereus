# Pre-existing build failure: cadre-host orchestrator type mismatch

## Command
```
cd packages/cadre-host && yarn build   # tsc -b
```

## Failure
```
src/orchestrator/host-process-orchestrator.ts(455,5): error TS2741:
  Property 'seedEndpoint' is missing in type
  '{ dockerId: string; healthEndpoint: string; metricsEndpoint: string; p2pPort: number; }'
  but required in type 'OrchestratorCreateResult'.
```

## Why this is pre-existing
- The `seed-frame-parsing-and-canonical-signing` ticket only touches
  `packages/cadre-host/src/update/manifest.ts` (canonicalJson re-export) within
  cadre-host; it does not touch the orchestrator.
- Verified by `git stash`-ing the manifest.ts change and rebuilding cadre-host at
  HEAD (2a3cbdf): the same `host-process-orchestrator.ts(455,5)` error reproduces
  with my change removed (`HEAD_BUILD_EXIT=2`).
- The error is a `OrchestratorCreateResult.seedEndpoint` type mismatch in a
  subsystem unrelated to manifest signing or seed-frame parsing.

## Work-around used to validate this ticket
- cadre-host full `yarn build` (tsc -b) cannot be made green from within this
  ticket. The manifest refactor itself was validated by running the manifest
  vitest suite (`packages/cadre-host/src/update/__tests__/manifest.test.ts`),
  which vitest transpiles per-file (no project-wide tsc gate). No source was
  disabled or modified to work around the orchestrator error.
