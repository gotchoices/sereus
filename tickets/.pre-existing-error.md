# Pre-existing error: reference-app-web typecheck (cadre-web.ts libp2p key type skew)

## Command
```
yarn workspace @serfab/reference-app-web run typecheck
```
(= `tsc --noEmit` in `packages/reference-app-web`)

## Failing output (excerpt)
```
src/lib/cadre-web.ts(286,3): error TS2322: Type 'PrivateKey' is not assignable to type 'PrivateKey | undefined'.
  Type 'RSAPrivateKey' is not assignable to type 'RSAPrivateKey'.
    ... import("C:/projects/optimystic/packages/db-p2p-storage-web/node_modules/@libp2p/interface/.../keys")
        vs import("C:/projects/sereus/node_modules/@libp2p/interface/.../keys")
src/lib/cadre-web.ts(323,34): error TS2345: Argument of type 'PrivateKey' is not assignable ...
```
Two errors, both in `src/lib/cadre-web.ts` (lines 286 and 323). They are a cross-package
type-identity mismatch: the linked `../optimystic/packages/db-p2p-storage-web` (via root
`package.json` `resolutions`) bundles its own copy of `@libp2p/interface`, whose
`PrivateKey`/`RSAPrivateKey`/`Uint8ArrayList` types are structurally-but-not-nominally
identical to `sereus/node_modules/@libp2p/interface`.

## Why this is pre-existing (not caused by this ticket)
- This ticket (`turn-credential-issuance-service`) touched exactly one file in this package:
  `packages/reference-app-web/src/lib/ice-config.ts`, and the change is **comment-only** (a
  doc-comment update; `git diff --stat` = 6 insertions / 3 deletions, all `*`-prefixed lines).
- `cadre-web.ts` — where both errors occur — is **not** modified by this ticket
  (`git status --porcelain` shows it clean). The errors therefore reproduce at HEAD
  independent of this ticket's diff.
- The errors are about libp2p private-key types from cross-linked optimystic workspaces;
  they have nothing to do with the ICE-config / TURN-credential work.

## Work-around taken
None needed for this ticket — the change is comment-only and cannot affect typecheck.
The new issuer service (`ops/docker/turn-credential-issuer/`) was validated independently:
`tsc -p tsconfig.json` compiles clean, and `node ops/test/check-turn-creds.mjs --self-test`
passes (12 checks). `ops/**` is outside the web typecheck scope.
