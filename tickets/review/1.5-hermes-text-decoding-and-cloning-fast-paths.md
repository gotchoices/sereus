GitHub #51 (kjeib, Sereus Health). Hermes on bare React Native has neither `TextDecoder` nor `structuredClone`; `polyfills/hermes.js` installs both. The reporter's profile put 6.6 s of `TextDecoder.decode` and 3.2 s of `structuredClone` into two writes. Both blocks are rewritten from the patch in the issue, reviewed and changed as below. Both stay behind their `typeof globalThis.X` guards, and both still call `markPolyfilled`.

## What changed

**Decode.** WHATWG UTF-8 decoding with replacement (Encoding Standard §9.1.1 state machine, with lower/upper continuation bounds). A leading ASCII run is turned into strings straight from the input. The rest is written into one module-level `Uint16Array(CHUNK + 1)` (CHUNK = 4096) and flushed with `String.fromCharCode.apply`. The constructor, `RangeError` and fields are unchanged. `decode` now passes `this.ignoreBOM` (always false today) instead of stripping the BOM unconditionally. The `stream` option is still ignored, as before.

**Clone.** `cloneValue` copies primitives, plain objects (prototype `Object.prototype` or `null`), arrays (holes kept), standard typed arrays, `ArrayBuffer`, `DataView`, `Date`, `RegExp`, `Map` and `Set`, with a `Map` memo for shared references and cycles. Any other value anywhere in the graph, or any call with `options`, sends the whole original value to `@ungap/structured-clone`.

## Where this departs from the #51 patch

- **Returned sentinel, not a thrown one.** Each copier returns a private `UNSUPPORTED` symbol, and its caller passes it up. No try/catch is involved, which follows AGENTS.md ("exceptions … not control flow"). The cost is one comparison per child.
- **`__proto__` keys.** The patch did `out[key] = …`, which for a `__proto__` key (JSON.parse makes it an own property) sets the copy's prototype instead. The copy now uses `Object.defineProperty` for that key, as native does. The test covers it.
- **Options are not forwarded to ungap.** Before this change the polyfill called ungap with the value only, dropping `options`. The patch forwarded them, and that would switch on ungap's non-standard `json`/`lossy` modes for any caller that passed them. A call with options still goes to ungap, as the ticket requires, but the options are still dropped.
- **Decomposed.** Small named functions (`pushAsciiRun`, `pushDecoded`, `pushString`, `clonePlainObject`, `cloneArray`, `cloneView`, `cloneMap`, `cloneSet`). The per-byte decode loop stays in a single function so it makes no call per byte. Tabs, braced blocks.
- **The ungap `require` must stay eager.** It runs before `globalThis.structuredClone` is assigned. ungap's default export picks a global `structuredClone` at load time, so loading it lazily would make the fallback call this polyfill. The code has a comment saying so.

## Tests (all in `hermes-polyfills.spec.ts`)

- `decodes UTF-8 without a TextDecoder, as Node's native one does` replaces the one-line `héllo` test. It compares the polyfill with Node's native `TextDecoder` on a fixed table plus seeded random inputs. The table: BOM variants, overlong forms, surrogates, U+D7FF, above U+10FFFF, U+10FFFF, every truncation, the four cases from #51, and stray or never-valid bytes. Five long texts: 9000 ASCII; 5000 ASCII then `é`; `é` followed by 3000 emoji, which puts a surrogate pair across the 4096 flush. The random inputs (mulberry32): 4000 strings of up to 24 bytes and 4 of up to 10,000, biased to UTF-8 boundary bytes. Runs in about 20 ms.
- `structuredClone › copies plain data itself, as native structuredClone does, keeping shared references`. One graph with a cycle, a shared object, a sparse array, two views over one buffer (plus `byteOffset`s), `Map`/`Set` sharing an object key, `Date`, `RegExp`, scalars including bigint and `undefined`, a null-prototype object and a `__proto__` key. Checks: `toStrictEqual` to native, identity relations, and **nothing handed to ungap**.
- `structuredClone › sends a graph holding anything else, whole, to @ungap/structured-clone`. A class instance nested below shared plain data, and a Node `Buffer`. Checks: exactly one ungap call, given the original value (`toBe`), and the result `toStrictEqual` to native.
- Harness change: `evaluatePolyfill` wraps the real ungap module and records each value it receives (`run.ungapClones`). This is needed because under Node ungap delegates to native `structuredClone`, so without the record a fast path that always gave up would pass every comparison.

Mutation check, run by hand and not committed. Each of these makes a test fail: the old polyfill; dropping the `__proto__` case; sending `Buffer` down the fast path; skipping an unsupported child instead of giving up; a `CHUNK`-sized buffer; no U+FFFD for a truncated tail; not preserving holes.

## Known gaps, for the reviewer

- **No Hermes run here.** There is no Hermes VM on this Windows machine (only `hermesc`, and not even that under `node_modules/react-native/sdks`). The Hermes CLI vectors and the S7 timings (7.1–7.7 s per write before, 1.4–1.6 s after) are the reporter's, measured on **their** patch. This version has the same algorithms but differs in structure: one function call per container, a sentinel comparison per child, and a `key === '__proto__'` comparison per object key. Nobody has timed it on Hermes. Confirming the speed on a phone follows the device-run convention in `blocked/rn-native-noise-crypto-device-run`.
- **Array named properties.** The algorithm also copies an array's own non-index enumerable properties, and native does. This copy does not, and neither did ungap. A `NOTE:` at `cloneArray` explains it.
- **Not handled by the fast path, all unchanged from before because they go to ungap:** resizable or shared `ArrayBuffer`s (a `SharedArrayBuffer` goes to ungap), Proxies of plain objects (copied as plain objects, which ungap also did), and `structuredClone()` called with no argument (returns `undefined`; native throws).
- **NativeScript copy.** `reference-app-ns/src/polyfills/hermes.ts` still has the old decoder. Filed as `backlog/bug-ns-textdecoder-misdecodes-invalid-utf8`.
