## Why `@optimystic/db-p2p-storage-web` is listed

The existing vitest suite (`node-local-slots.spec.ts`) imports it only as a
TypeScript type, which erases at runtime — that suite alone never touches its
`dist`. It's listed anyway: it's a declared, link-resolved dependency the app
itself runs, and the drift spec (`build-targets.spec.ts`) checks the manifest,
not the import graph. Accepted cost: a stale build there fails this unit suite
over code it doesn't currently exercise — same bias toward a loud, fixable
failure the whole guard is built on. Documented in the `TARGETS` comment in
`global-setup.ts`.
