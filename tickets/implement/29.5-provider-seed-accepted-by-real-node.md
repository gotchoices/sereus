## Design decisions already baked into the scenario (don't re-derive)

- Owner authority via cadre-host's `HostProcessOrchestrator`, port band
  20200–20339 (19600–20199 are claimed by the cadre-host suites),
  `libp2pPort: 0`.
- No assertion on `createContainer`'s returned `status`: `MemoryStore` hands
  back live references, so the async provisioning loop mutates it under the
  test ('pending' → 'creating' race, seen in run 1).
- Step 5 restarts node A through the orchestrator directly (same containerId →
  same volume → same identity, NO pins) because `ContainerService` can only
  mint fresh `ctr_` ids; the store record is then patched with the fresh
  endpoints/token and `status: 'running'`.
- Negative assertions are gated on the node being `running` first; failure
  messages dump the child's `node.log`.

## Arm added by `verify-ddl-retry-engages` (measured 2026-08-03, 7 runs at HEAD)

Step 4's trust-refusal assertion fails for a reason unrelated to node startup, and
it reproduced on 4 of the 7 runs — including runs where every node started fine:

```
AssertionError: expected 'Seed endpoint returned 400: {"success…' to match /(neither|not).*(anchored|pinned)/i
+ Received: "Seed endpoint returned 400: {\"success\":false,\"error\":\"seed is required\"}"
```

`seed is required` is the node's own "you posted no seed body" refusal, not the trust
policy's. So node B refused for the wrong reason, and the assertion that it refused
*because of the pin* never actually got exercised. The bearer-token half of the step
(the 401) passes throughout.

Worth checking before the polling workaround the TODO above suggests: a refusal whose
reason is `seed is required` means the request body never arrived, which is a delivery
bug, not a race — polling would just retry a malformed POST. Look at how
`ContainerService.applySeed` serializes the body versus what the node's `POST /seed`
handler expects to parse.

The scenario CAN go fully green: runs 4 and 5 of 7 passed all five steps outright,
which is the first time this scenario has been observed green end to end.
