## What the source now does (committed; from prior runs' notes)

- `strand-formation-protocol.ts`: `FormationContactMessage` gained `peerKey`
  (joiner's base64url ed25519 public key), `usageStampId` (joiner-minted
  nonce), `peerSignature` (consent-digest signature); `partyId` kept for
  logs/`memberKey`. `FormationListenerOptions.provisionStrand` is now
  `(contact: FormationContactMessage, signal?)`. Private
  `isJoinerConsentValid(id, contact)` runs in `runSession` BEFORE
  `validateToken` and rejects with `approved: false, reason: 'Invalid joiner
  consent'` when: `requireEd25519PublicKeyB64` throws (caught, logged WITHOUT
  echoing the remote value), `ed25519PublicKeyB64FromPeerId(contact.partyId)`
  is null or ≠ `contact.peerKey`, or `verifyFormationConsent` over
  `canonicalJson(contact.disclosure)` fails. The DB CHECK stays the authority.
- `strand-formation-manager.ts`: `formStrand(invitation, disclosure, consent,
  node)` — third param `consent: { peerKey; usageStampId; peerSignature }`,
  placed onto the contact. `provisionAsResponder(contact, signal?)` serializes
  with `canonicalJson` (was `JSON.stringify`); `recordUsage` /
  `provisionAndRecord` calls pass `peerKey`/`peerSignature`/`usageStampId`;
  `provisionUnbound(contact, disclosureText, signal?)` reads `contact.partyId`
  for the provisioner/placeholder branches. Joiner nonce-reuse `unique`
  failure still lands in the generic 'Formation conflict, retry' catch arm —
  a test should confirm.
- `strand-solicitation.ts`: initiator `formStrand` mints consent when using
  the real transport: `ed25519KeyPairFromLibp2p(privateKey)` →
  `generateStampId(memberKey)` → `fullDisclosure = { ...disclosure, partyId:
  memberKey }` built ONCE → signs `formationConsentMessage({ token,
  usageStampId, peerKey: publicKeyB64, disclosure:
  canonicalJson(fullDisclosure) })` → passes `fullDisclosure` + consent to
  `manager.formStrand`. The no-node placeholder fallback signs nothing.
  `recordFormationComplete(token, peerKey, strandId, consent: { usageStampId;
  peerSignature }, disclosure = '')` — widened 4th param, passes through to
  `recordUsage`.
