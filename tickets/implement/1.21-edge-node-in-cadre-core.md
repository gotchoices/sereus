# The edge node in cadre-core

GitHub #45. `createPhoneNode` (`@serfab/cadre-rn/phone-node`) is the bring-up every app that runs a `CadreNode` on an edge device needs: one transition queue for start, stop, restart, join and dissolve; cleanup after a failed start; event subscriptions re-applied to each rebuilt node before it starts; the edge config with relays through `network.relayAddrs` and `requireRelay: false`; owner genesis bounded at 60 s; the saved start; the join, strand move, dissolve and removal sequence. Its only React Native tie is `leveldb: LevelDBNative` and the secure store. This ticket moves all of it into cadre-core behind a storage-neutral platform interface. The web app (`reference-app-web-runs-the-edge-node`) and the NativeScript app (`reference-app-ns-runs-the-edge-node`) adopt it afterwards.

Approved on #45 (maintainer, 2026-10-15): the shared module lives in cadre-core. A subpath, not the root export, so cadre-host and the CLI never load it.

## The platform interface

The current `PhoneNodePlatform` minus the two native ties, which become a `KeyStore` and an `EdgeNodeStorage`:

```ts
export interface EdgeNodePlatform {
	/** Identity (`DEFAULT_IDENTITY_KEY_ID`), owner key (`DEFAULT_OWNER_KEY_ID`), joined-strand records and strand-move records: everything secret. */
	keyStore: KeyStore;
	storage: EdgeNodeStorage;
	/** Given the relays. Default: WebSockets and circuit relay. */
	transports?: (relayAddrs: readonly string[]) => Libp2pTransports;
	/** Listen addresses besides the `/p2p-circuit` entry cadre-core adds for a named relay. Default `[]`: an edge device cannot accept a connection. The web tab returns `['/webrtc']` when it has relays. */
	listenAddrs?: (relayAddrs: readonly string[]) => string[];
	noiseCrypto?: { build: (mode: NoiseCryptoMode) => NoiseCryptoInterface | undefined; defaultMode: NoiseCryptoMode };
	names?: Partial<EdgeNodeNames>;
	allowPrivateDial?: boolean;
	ownerGenesisTimeoutMs?: number;
	dataVersion?: string;
	configure?: (config: CadreNodeConfig) => CadreNodeConfig;
}

/** Keys inside the node-local store: `savedStartKey`, `dissolveMarkerKey`, `linkRequestKey`, `recommendationsKey`, with today's defaults. */
export interface EdgeNodeNames { ... }

export interface EdgeNodeStorage {
	/** Names the storage. `createEdgeNode` refuses a second starting, joining or running node over the same id, and replaces a stopped one (today's per-`storagePrefix` rule). */
	readonly id: string;
	/** One storage scope's raw block storage. Synchronous, as `CadreNodeConfig.storage.provider` is; a platform whose opener is async returns `lazyRawStorage(...)`. Same handle for the same scope until `close`. */
	rawStorage(scope: string): IRawStorage;
	/** Delete a scope's storage. No handle on it may be open. Resolves when it is gone or was absent. */
	destroyScope(scope: string): Promise<void>;
	/** The node-local key-value store. Usable with no node running: reopens after `close`. */
	nodeLocal(): NodeLocalKv;
	/** Flush and close the node-local store, then close every handle `rawStorage` opened. A failure closing one is logged and the rest still close. */
	close(): Promise<void>;
	/** Per-party trusted-owner anchor. Absent: the node-local key `trusted-owners.<partyId>`. The phone puts it in the secure store. */
	trustedOwnerSlot?(partyId: string): RemovableSlot;
}

/** The kit's `KvStoreApi` plus `delete`. */
export interface NodeLocalKv { get(key: string): Promise<string | undefined>; set(key: string, value: string): Promise<void>; delete(key: string): Promise<void>; flush(): Promise<void> }

export interface RemovableSlot extends DurableSlot { remove(): Promise<void> }
```

`EdgeNode` is today's `PhoneNode` interface unchanged, renamed, plus one read-only property the web app's card needs:

- `unfinishedRemoval: { partyId: string; error: Error } | null`: the removal a dissolve marker names that the last start tried to finish and could not (`finishRemovalAtStart` currently logs and drops the error). Cleared by the start that finishes it.

One behavior change, taken from the web app's copy (`reference-app-web/src/lib/web-join.ts` → `finishStrandMove`), which is the better of the two:

- `finishStrandMove()` on a joined party with no owner signer wired first runs `wireJoinedOwner(node, false)` once (the slot key, then the identity key), reporting `owner: 'enrolled'` when that wires one, and only then adopts. An owner grant whose `OwnerKey` row arrived after the join stopped waiting (`wireJoinedOwnerKey`'s 60 s) is then picked up by Retry rather than refused with `StrandMoveNotOwnerError`. Still throws `StrandMoveNotOwnerError` when no key wires.

Deliberately not taken from the web copy: its `finishRemovalAtStart` deletes, without acting on it, a dissolve marker that names the party being started. The kit's rule (finish the removal: it was decided before the marker was written) stays, and the existing NOTE on `forgetRemovedParty` about a start of a removed party's cached options covers that case.

Also exported: `EdgeNodeStatus`, `EdgeJoinProgress`, `JoinCadreOptions`, `JoinCadreResult`, `EdgeNodeOptions`, `EdgeNodeOrigin`, `SavedStart`, `parseSavedStart`, `serializeSavedStart`, `buildEdgeNodeConfig`, `runOwnerGenesis`, `wireJoinedOwnerKey`, `DEFAULT_OWNER_GENESIS_TIMEOUT_MS`, `DEFAULT_OWNER_KEY_LABEL`, `OwnerGenesisResult`, `attachStrandWhenWritable`, `retryAfterRestart`, `DEFAULT_STRAND_PATIENCE_MS`, the three errors, `PendingStrandMove`, `StrandMoveOutcome`, `DissolveFormerPartyOptions`, `DEFAULT_EDGE_NODE_NAMES`, the per-party node-local key functions (`bootstrapPeersKvKey`, `enrolledMachinesKvKey`, `strandNetworkKvKey`, plus `trustedOwnersKvKey` for the default anchor), `kvStoreSlot`, and `lazyRawStorage`.

### `lazyRawStorage`

`lazyRawStorage(open: () => Promise<IRawStorage>): IRawStorage`: every method awaits one cached `open()` before delegating; a rejected open is forgotten, so the next call retries; async-iterator methods open only once iteration starts. Generalized from `reference-app-ns/src/ns-storage.ts` (`makeLazyNsStorage`), which the NativeScript ticket deletes. It ships here because the platform contract requires a synchronous `rawStorage` and both the browser (IndexedDB) and NativeScript (SQLite) open asynchronously. Per-scope handle caching, and closing, stay the platform's.

## Edge cases & interactions

- **One-per-storage guard** keys on `storage.id`; the phone's id is its `storagePrefix`, so `node.spec.ts` "one per app" cases hold. Verified by those tests.
- **Node-local store across a stop.** `nodeLocalRecords()`, `linkRequestSlot()`, `loadSavedStart()` work with no node running and wait for an in-flight stop before touching the store, as now (the existing NOTE about restart/join/dissolve windows moves with the code). The LevelDB adapter must reopen its handle after `close()`. Verified by `node.spec.ts` ("answers loadSavedStart during a stop", "closes every database on stop").
- **`close()` ordering.** The node-local store is flushed and closed before its database; a throwing close of one handle does not leave others open (`node.spec.ts` "closes every database on stop even when stopping the node throws").
- **Default anchor slot.** With no `trustedOwnerSlot`, the anchor is the node-local key `trusted-owners.<partyId>`, and the dissolve's `finishRemoving` deletes it through `remove()`. The phone passes its secure-store slot, so its anchor never lands in LevelDB. Verified by inspection plus the dissolve cases of `node.spec.ts`.
- **`destroyScope` is async** where `leveldb.destroy` is sync: `finishRemoving` awaits it; a throw keeps the marker for the next start, as now.
- **`finishStrandMove` on a joined party** runs in turn with the other transitions, as now; the extra wiring pass must not run on a founded party (genesis rules) and must not replace an owner signer already wired. One test in `node.spec.ts`'s join describe, the only new behavior with branching: a joined party whose owner row for the app's slot key is added after the start settled as `member` (add it through a second node, or through `adoptStrandBundle`-style direct control writes as the existing cases do) → `finishStrandMove()` resolves with the adoption report and `status.owner` becomes `enrolled`.
- **`unfinishedRemoval`** is set when `finishRemovalAtStart` fails and cleared by a start whose finish succeeds, or that finds no marker. A dissolve or removal that finishes the marker also clears it. By inspection.
- **`lazyRawStorage`**: one `open()` shared by concurrent first calls; a rejected open reaches the calls awaiting it and is retried by the next call; iteration methods open lazily. Port the three `ns-storage.spec.ts` cases to cadre-core as its test (that spec is deleted by the NativeScript ticket).
- **Bundling.** The subpath imports `@libp2p/websockets` and `@libp2p/circuit-relay-v2` (both already cadre-core dependencies) and nothing from `node:*`. Confirm the React Native build-target and Metro checks in cadre-rn still pass, and that `@serfab/cadre-core`'s root `index.ts` does not import the subpath.
- **Stale-build guard.** cadre-rn's tests run against cadre-core's `dist`: rebuild cadre-core (`yarn workspace @serfab/cadre-core build`) before running them. cadre-core is this repo's package, not a sibling.
