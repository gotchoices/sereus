# Release notes — pending

## Dependencies

- Every `@optimystic/*` dependency now requires ^1.14.0. Optimystic 1.14.0:
  - **A failed cancel no longer leaves a write stuck.** When a member of a three-machine group answered a write's first step and then went silent, the write's cancel could fail too, and the writer refused every later write to the same blocks until it restarted. The cancel is now owed and re-sent until it lands, so the next write after the member returns commits. (In Sereus, found by `control-write-degraded-cohort-member`.)
  - **A one-collection write on a two-machine group costs the other machine 3 requests instead of 4.** That covers a two-machine strand's single-table writes. A write to an indexed table still costs 4 per collection.

## Known limitations

- **A writer that exits before its owed cancel lands leaves its pending record on the other members.** Those members refuse writes to the same blocks until a sweep for such records exists upstream.
- **FRET allows 10 s for a maintenance redial, and Sereus cannot raise it.** A relayed dial on Sereus's declared link can take up to 21.5 s. Sereus's own strand redial covers reconnection meanwhile; Optimystic needs to pass the setting through (filed upstream).
- **A removed machine keeps access to the cadre's strands.** Removal stops its control-database access only. What removal should do with strands is not decided yet.
