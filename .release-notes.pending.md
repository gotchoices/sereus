# Release notes — pending

- **Requires `@optimystic/*` NEXT (the release after 1.1.0).** Each strand write now needs fewer network round trips. A two-party insert opens 4 cluster-protocol streams instead of 9. Over a relay with 150 ms added each way, an insert took 4.5–5.9 s, down from 8.9–10.2 s (with one run at 37.9 s). Concurrent inserts by a founder and a `storage`-profile joiner no longer fail with `TornActionError`: 0 of 12 pairs failed, down from 5 of 12. Reads are unchanged. Measured in sereus's relay topology; see gotchoices/sereus#13.
