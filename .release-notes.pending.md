# Release notes — pending

## Upgrading

- **Control stores written by 1.16.0 or earlier must be recreated on every machine.** This release refuses such a store at start with `ControlStoreIncompatibleError`, because its control schema cannot be applied to it without losing data. Delete the control store on every machine of the party and found the party again, as `docs/architecture.md` → "Recreating a control store" describes. Stores written from this release on record their control schema version.
