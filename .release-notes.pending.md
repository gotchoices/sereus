# Release notes — pending

## Fixes

- **A strand write on bare React Native spends far less time in the kit's Hermes stand-ins** (`cadre-rn`, gotchoices/sereus#51). Hermes has no `TextDecoder` or `structuredClone`, and the kit's replacements took half the JavaScript thread's busy time during a write: the decoder built its string one character at a time, and every clone went through `@ungap/structured-clone`. The decoder now builds its output 4096 code units at a time, and plain data (objects, arrays, typed arrays, `Date`, `RegExp`, `Map`, `Set`) is copied directly; anything else still goes to ungap. On a Galaxy S7 (debug build, solo strand), saving one log entry of four rows went from 7.1–7.7 s to 1.4–1.6 s. Found, measured and patched by kjeib (Sereus Health).
- **The kit's `TextDecoder` decodes invalid UTF-8 as the Encoding Standard does** (`cadre-rn`, gotchoices/sereus#51). It read continuation bytes without checking them, so a truncated `F0 9F 98` decoded as a whole emoji, `E2 41` lost the `A` and `C0 80` became NUL. Each invalid sequence now decodes as one U+FFFD, matching the native decoder.
