# Release notes — pending

- **Requires `@optimystic/*` 1.1.0.** It fixes a commit refusal in two-machine cohorts. When the machine coordinating a write was missing the block the write was based on, the commit was refused with `commit-not-durable: 1 of 2 … (local-executed)`, even though the other machine held the write. The most common case was a party that wrote immediately after `addStrand` resolved. Its first write paid for a refused commit and a retry. That write now commits on the first attempt.
- **The browser build of `@serfab/quereus-plugin-sereus` (`./plugin-browser`) is now minified.** It is about 1.9 MiB raw and 0.6 MiB gzipped, down from about 4.7 MiB and 1.1 MiB. The exports and behaviour are unchanged. The source map, `dist/plugin-browser.js.map`, still ships beside it with the original sources embedded, so browser devtools still show readable code.
