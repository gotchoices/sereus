# Release notes — pending

## Joining a strand tries every address in the invitation

A join now tries every address the invitation carries, until one connects, instead of only the first. An inviter with reservations on two relays is reachable while either relay is up. All the addresses share the one formation dial budget, so a relay that does not answer at all can still use up that budget before the next address is tried. When every address fails, the error now names each address's own failure.
