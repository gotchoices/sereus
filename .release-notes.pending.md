# Release notes — pending

- **Native crypto for encrypted connections: `NetworkConfig.noiseCrypto`.** An app can now give a Cadre node its own implementation of the crypto used to encrypt its connections (libp2p-noise). The node passes it to the control node and to every strand node. On React Native, Metro resolves libp2p-noise's browser build, which is pure JavaScript, and on Hermes (no JIT) that cost dominates connection setup on slower phones (gotchoices/sereus#13). The usual pattern is to spread `noisePureJsCrypto` from `@optimystic/db-p2p` and override the hashing and ChaCha20-Poly1305 functions with native ones. When the option is unset, nothing changes. Only local primitives change, so a node that sets it still interoperates with one that doesn't. The reference app does not set it yet.
- **Requires `@optimystic/*` 1.3.0.** 1.3.0 adds the `noiseCrypto` option above. 1.2.0's own notes said it required optimystic 1.2.0, but its package ranges still accepted `^1.1.0`. With this release, an app whose lockfile pinned optimystic 1.1.0 also moves off 1.1.0's slower commit path.
