# Release notes — pending

**Do not release until the optimystic patch for Quereus 4.20.0 is published and the `@optimystic/*` floors are raised to it.** optimystic 1.5.0 is unsafe with Quereus 4.20.0 after a failed `apply schema`, and this release needs 4.20.0.

- The strand membership writer runs its statements as one Quereus atomic batch (`exec(..., { transaction: true })`). A failed background membership write can no longer sweep in, and lose, an app write queued behind it. Requires `@quereus/quereus` 4.20.0.
